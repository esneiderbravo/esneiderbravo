## ⭐ Flagship — speclaw

> **AI agents are brilliant and blind** — brilliant at writing code, blind to *your* project's rules.
> **[speclaw](https://github.com/esneiderbravo/speclaw)** turns any repo into a spec-driven, agent-ready codebase:
> a constitution built from your real code, a local code graph (Compass) that saves tokens, and a disciplined
> spec workflow. **No LLM, no cloud, 100% local.** Ships as a CLI **and** an MCP server.
